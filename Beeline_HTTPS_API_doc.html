Протокол HTTPS

Описание отправки сообщений через протокол HTTPS

Скачать примеры на PHP 7

Для совместимости с предыдущей версией класса на PHP 5, был добавлен класс-обёртка, который позволяет использовать функциональность предыдущей версии, без необходимости изменений в вашем коде. Также класс-обёртка содержит свой собственный загрузчик классов. Подробная документация по классу находится в приложенном архиве в файле «README-for-advanced.md».

Для начала использования класса рекомендуем прочитать «README.txt» из архива с примерами.

Параметры запроса

Параметр
Значение
URI запроса https://a2p-sms-https.beeline.ru/proto/http/
Метод запроса GET или POST
Заголовок запроса Content-Type: application/x-www-form-urlencoded; charset=utf-8

Если не указана кодировка, то кодировка utf-8 используется по умолчанию. При использовании другой кодировки, укажите её в заголовке запроса. Например: charset=windows-1251

Максимальная длина сообщений не должна превышать 2000 символов!

Передаваемые в запросе параметры:

Параметр
Значение
Заголовок ответа Content-Type: text/xml; charset=utf-8
Content-Encoding: gzip

Важно!

Платформа всегда возвращает ответ в архивированном виде. Для получения ответа в простом виде в запросе необходимо передавать gzip=none.

Авторизация требуется при каждом подключении к серверу

Параметр
Значение По умолчанию

Авторизация с использованием API токена:

При использовании HTTPS протокола возможна авторизация с помощью API токена. Для этого необходимо:

  • передавать в заголовке X-ApiKey значение ApiKey Ваш API токен
  • при использовании токена логин с паролем указывать не нужно. Передается только сам токен, иначе возникнет ошибка
  • передавать тело POST-запроса в JSON формате
  • Добавить в адрес запроса /rest. Итоговый адрес: https://a2p-sms-https.beeline.ru/proto/http/rest

Пример указания токена: 

'X-ApiKey: ApiKey GvEqzI1TSmw7bDn)JC4wG424u8Po5txpC7S$tiU:KJ/x4I+Udb'

Важно!

  • Создавать и использовать API токен может только пользователь с ролью Суперпользователь
  • Создается токен в разделе Карточка пользователя на вкладке API токены https://a2p-sms.beeline.ru/cabinet/users/usercard
  • При создании можно указать название токена, время его действия и протокол: HTTPS или Elmup (последний используется для интеграции со сторонним сервисом)
  • После создания токена необходимо его сохранить, получить значение повторно невозможно
  • В разделе Настройки пользователь с ролью Суперпользователь может отслеживать и управлять списком всех токенов кабинета.
  • Список токенов располагается в разделе Настройки https://a2p-sms.beeline.ru/cabinet/settings

time_local Выбор часового пояса для параметра time_period:

- F: Flash SMS сообщение		 Пустое значение

Используется только для sms_type = W, то есть Wap push сообщения.
wap_expires Дата и время, когда истекает срок доставки Wap push сообщения.
(Формат: dd.mm.yyyy hh:ii:ss (дд.мм.гггг чч:ми:сс))

Отправка эмодзи в платформе A2P

Произвести отправку эмодзи можно как через веб-интерфейс так и через протокол https.
Для отправки эмодзи через протокол HTTPS их нужно добавлять в виде символа, а не UTF или HTML кода.

  • Правильно: 😎
  • Неправильно: 1F60x

Общий способ добавить эмодзи в набираемый текст:

  1. Перейти в библиотеку эмодзи
  2. Выбрать необходимый эмодзи и нажать кнопку «Копировать»
  3. Вставить эмодзи в текст 🤩

На платформе Windows можно открыть библиотеку эмодзи сочетанием клавиш «Win + .». Необходимо просто кликнуть на нужный символ.

На платформе iOS для открытия панели с эмодзи зажмите одновременно клавиши «Command + Control + Пробел», чтобы появилась панель с эмодзи. Далее выберите нужный смайлик и вставьте его в текст нажатием клавиши Enter.

Получение статусов сообщений асинхронно

Данный вариант позволяет получать статусы сообщений в реальном времени. Для настройки нужно указать в разделе «Личный кабинет» → «Настройки» параметр «URL скрипта для приёма статуса отправленных SMS». Как только система получит статус сообщения, она немедленно перешлёт его на указанный URL по протоколу HTTPS методом POST.

Передаваемые в запросе параметры:

Параметр
Значение
ORDID Номер сообщения (соответствует значению атрибута ID тэга SMS, возвращаемого при отправке сообщения)
CNRID ID контрагента
RESCOUNT Количество сообщений для тарификации
STATUS Код статуса:
- 2 – сообщение доставлено;
- 3 – время попыток доставить сообщение оператором истекло;
- 5 – сообщение не может быть доставлено (ошибка в номере, номер не существует и т.д.);
- 7 – статус сообщения неизвестен;
- 8 – сообщение не принято оператором;
- 20 – отправка отменена пользователем;
- 21 – системная ошибка;
- 22 – оператор не сообщил о состоянии сообщения за отведенное время.
FINALTIME Время получения финального статуса в UTC

Получение данных и статусов сообщений

Получить статусы сообщений можня 3 различными способами:

Параметр
Значение
action status
sms_id Способ 1 - Номер сообщения.
Соответствует значению атрибута ID тэга SMS, возвращаемого при отправке сообщения.
sms_group_id Способ 2 - Номер рассылки.
Соответствует значению атрибута sms_group_id тэга result, возращаемого при отправке сообщений.

Формат: dd.mm.yyyy hh:ii:ss (дд.мм.гггг чч:мн:сс)
Период не должен быть больше 4 дней до текущей даты!

Сервис сокращения ссылок для протокола HTTP

На платформе действует функция автоматического распознавания и сокращения длинных ссылок для сообщений, передаваемых по протоколу HTTPS. Чтобы воспользоваться этой опцией, необходимо передавать в запросе параметр shortenLinks=true

Важно!

Опция сокращения действует только для ссылок, которые начинаются на http:// или https://. Если в тексте сообщения содержится две и более ссылки, они также будут сокращены.

Примеры:

https://a2p-sms-https.beeline.ru/proto/http/?user=LOGIN&pass=PASSWORD&action=post_sms&sender=SENDER&message=Check https://a2p-sms.beeline.ru&target=NUMBER&shortenLinks=true

Отправка сообщений посредством метода JSON

Отправка одного сообщения

Для отправки сообщений методом JSON необходимо сформировать POST-запрос на URL https://a2p-sms-https.beeline.ru/proto/http/rest следующего вида: 

{
    "user":"xxx",
    "pass":"xxx",
    "action":"post_sms",
    "sender":"Your_Sender",
    "message":"text_1",
    "target":"+79031112233"
}

####Важно! При использовании метода JSON адрес сервера обязательно должен заканчиваться на «/rest» в отличии от простого HTTPS.

При успешном выполнении запроса платформа вернет соответствующий ответ также в виде JSON:

Пример:

https://a2p-sms-https.beeline.ru/proto/http/rest 

{
    "user":"xxx",
    "pass":"xxx",
    "action":"status",
    "sms_id":"508909732338141600334"
}

или 

    {
        "user":"xxx",
        "pass":"xxx",
        "action":"post_sms",
        "data": [{
            "action": "status",
            "sms_id":"508909732338141600334"

Опция сокращения гипер-ссылки в тексте

В платформе действует функция автоматического распознавания и сокращения длинных гипер-ссылок для сообщений, передаваемых по протоколу HTTPS. Чтобы воспользоваться этой опцией, необходимо передавать в запросе параметр shortenLinks=true

Важно!

Опция сокращения действует только для ссылок, которые начинаются на http:// или https:// , и если в тексте сообщения содержится две и более ссылки, они также будут сокращены.

Пример JSON-запроса: 

{
    "user":"xxx",
    "pass":"xxx",
    "action":"post_sms",
    "sender":" Your_Sender ",
    "message":" Check https://a2p-sms.beeline.ru",
    "target":"+79031112233",
    "shortenLinks":"true"
}

Ответ платформы: 

{
